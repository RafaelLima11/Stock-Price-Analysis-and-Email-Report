# Stock Price Analysis and Email Report

A Python project that retrieves historical stock prices, calculates key statistics, and prepares and sends a report through the Gmail interface.

## Features
- Retrieve historical stock market data
- Calculate maximum, minimum, and average prices
- Prepare an email report
- Automate interactions with the Gmail interface

## Technologies
- Python
- yfinance
- PyAutoGUI
- Pyperclip

## How to Run
1. Install the required dependencies.
2. Ensure a compatible desktop environment and browser are available.
3. Run the main Python script.

## Notes
Review the script before running it. Never upload passwords, API keys, or other credentials to the repository.

## Project Context
Developed as part of a Python programming course.
